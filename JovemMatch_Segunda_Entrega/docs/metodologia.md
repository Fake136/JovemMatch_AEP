# Metodologia de Trabalho – JovemMatch

## Quadro de tarefas

A equipe utilizou **GitHub Projects** (ou quadro equivalente) com as colunas:

| Coluna | Descrição |
|--------|-----------|
| Backlog | Itens planejados |
| Em andamento | Itens em desenvolvimento |
| Concluído | Itens finalizados |

## Cards da 2ª entrega (exemplo)

1. Implementar matching por habilidades
2. Atualizar status de candidatura no menu
3. Busca de vagas por cidade
4. Estatísticas do sistema
5. Expandir testes automatizados
6. Documentação técnica completa
7. Atualizar README com evolução
8. Gravar vídeo da 2ª entrega
9. Criar tag v2.0-segunda-entrega

## Evidência para avaliação

- Histórico de commits no repositório demonstrando evolução incremental
- Link do GitHub Projects do repositório (aba Projects)
- Esta documentação em `docs/metodologia.md`

## Como criar o quadro no GitHub (equipe)

1. Abra o repositório no GitHub
2. Aba **Projects** → New project
3. Crie as colunas Backlog / Em andamento / Concluído
4. Adicione os cards acima
5. Mova para Concluído conforme for finalizando
